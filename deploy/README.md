# KaamNow — Production Deployment on Oracle Cloud Free Tier (kind + Let's Encrypt)

Deploy the full KaamNow stack (FastAPI + React + MongoDB) to a free **Oracle Cloud ARM** server using **kind** (Kubernetes in Docker) with automatic **HTTPS via Let's Encrypt**.

**End result:** `https://kaamnow.com` live, SSL-secured, costing **₹0/month**.

---

## 📋 What you need before starting

1. ✅ A **GoDaddy** domain (you already have `kaamnow.com`)
2. ✅ An **Oracle Cloud Free Tier** account ([signup](https://www.oracle.com/cloud/free/)) — credit card needed for verification only, never charged
3. ✅ An **email** for Let's Encrypt cert notifications (any email works)
4. ⏱ ~30 minutes total

## 🅰 PHASE 1 — Create the Oracle Cloud server (one-time, ~10 min)

### 1.1 Sign up for Oracle Free Tier
Go to https://www.oracle.com/cloud/free/ and sign up. Pick a region close to you (Mumbai for India: **ap-mumbai-1**).

### 1.2 Create a VM instance
1. Console → **Instances** → **Create instance**
2. **Name**: `kaamnow`
3. **Image**: Click "Change image" → **Canonical Ubuntu 22.04** (Always Free eligible)
4. **Shape**: Click "Change shape" →
   - **Ampere** → **VM.Standard.A1.Flex**
   - OCPUs: **2**, Memory: **12 GB** (or up to 4 OCPUs / 24 GB — all free)
5. **Networking**: Keep defaults (creates a new VCN)
6. **SSH keys**: Either upload your own pubkey, OR click "Generate a key pair for me" and **download both** files
7. Click **Create** — wait ~2 min, copy the **Public IP**

### 1.3 Open ports 80 + 443 in Oracle's firewall
Critical step — Oracle blocks these by default:

1. Console → **Networking** → **Virtual Cloud Networks**
2. Click your VCN → **Default Security List**
3. **Add Ingress Rules** twice:

| Source CIDR | IP Protocol | Destination Port |
|---|---|---|
| `0.0.0.0/0` | TCP | `80` |
| `0.0.0.0/0` | TCP | `443` |

### 1.4 SSH into your server
```bash
chmod 400 ~/Downloads/ssh-key-*.key
ssh -i ~/Downloads/ssh-key-*.key ubuntu@<YOUR_PUBLIC_IP>
```

## 🅱 PHASE 2 — Pull code + run the deploy script (~15 min, mostly automated)

### 2.1 On the Oracle server: clone your repo
```bash
sudo apt-get update && sudo apt-get install -y git
git clone https://github.com/<your-username>/<your-repo>.git kaamnow
cd kaamnow
```

> If you haven't pushed to GitHub yet, click **"Save to GitHub"** in the Emergent chat first.

### 2.2 Run the one-command deploy
```bash
sudo LE_EMAIL="your-real-email@gmail.com" bash deploy/deploy.sh
```

This script does everything:
- ✅ Installs Docker, kubectl, kind
- ✅ Opens firewall ports
- ✅ Creates kind cluster (single-node, ports 80/443 mapped)
- ✅ Builds Docker images for backend + frontend
- ✅ Loads images into kind (no registry needed — saves bandwidth)
- ✅ Installs NGINX Ingress Controller
- ✅ Installs cert-manager + Let's Encrypt issuer
- ✅ Deploys MongoDB (with 2 GB persistent volume)
- ✅ Deploys backend with auto-generated JWT secret
- ✅ Deploys frontend
- ✅ Creates Ingress with TLS

When it finishes you'll see:
```
================ DEPLOY DONE ================
Admin login (save this!):
   email:    admin@kaamnow.com
   password: <auto-generated 12-char>
```

**⚠️ COPY THE ADMIN PASSWORD — it's only shown once!**

## 🅲 PHASE 3 — Point GoDaddy DNS to your server (~5 min + 5 min DNS propagation)

The deploy script prints your server's public IP at the end. Take that and:

1. Log into GoDaddy → **My Products** → `kaamnow.com` → **DNS** → **Manage DNS**
2. **Delete** any existing parked A records pointing at GoDaddy's parking IP
3. **Add records:**

| Type | Name | Value | TTL |
|---|---|---|---|
| A | `@` | `<your-server-public-ip>` | 600 |
| A | `www` | `<your-server-public-ip>` | 600 |

4. Save.

### Verify DNS propagation
```bash
dig kaamnow.com +short
# Should return your server IP within 1-5 minutes
```

Or use https://www.whatsmydns.net/#A/kaamnow.com to see global propagation.

### Let's Encrypt issues the cert automatically
Once DNS resolves to your server, cert-manager will trigger Let's Encrypt's HTTP-01 challenge and provision the TLS cert in ~30 seconds.

Watch it happen:
```bash
kubectl -n kaamnow describe certificate kaamnow-tls
# Look for "Certificate issued successfully"
```

### Test
```bash
curl -I https://kaamnow.com
# HTTP/2 200
# server: nginx
```

🎉 **Visit https://kaamnow.com — you're live!**

## 🛠 Day 2 — managing the deployment

All commands run from the project root:

```bash
make help              # see all commands
make status            # pods, services, ingress, certs
make logs APP=backend  # tail backend logs
make logs APP=frontend
make logs APP=mongodb

# After making code changes locally (then git pull on server):
make rebuild-backend    # rebuild + restart only backend
make rebuild-frontend   # rebuild + restart only frontend
make redeploy           # both

# Cert status (run if HTTPS isn't working):
make cert-status

# Mongo shell:
make mongo-shell

# Nuke everything:
make destroy
```

## 🐛 Troubleshooting

### "Pending" pods or images not loading
```bash
kubectl -n kaamnow describe pod <pod-name>
```
Usually means the image didn't load into kind. Re-run:
```bash
kind load docker-image kaamnow/backend:latest --name kaamnow
kind load docker-image kaamnow/frontend:latest --name kaamnow
```

### Let's Encrypt cert stuck on "pending"
- **Most common cause**: DNS hasn't propagated yet. Wait 5-10 min.
- **Second cause**: Ports 80/443 not actually open (check Oracle firewall rules + iptables).

```bash
kubectl -n kaamnow describe certificate kaamnow-tls
kubectl -n cert-manager logs -l app=cert-manager
```

If you hit the Let's Encrypt rate limit (5 failures/hour), switch to staging first:
```bash
# Edit deploy/k8s/40-issuer.yaml: replace acme-v02 with acme-staging-v02
```

### "503 Service Unavailable" at https://kaamnow.com
```bash
kubectl -n kaamnow get pods
# Make sure backend AND frontend show 1/1 Ready
```
If backend's not ready, check logs:
```bash
make logs APP=backend
```

### Free tier ARM image build is slow
First build of frontend can take 5-8 minutes on 2 OCPUs (lots of npm install). Subsequent builds reuse Docker layer cache and are ~30 seconds.

### "Permission denied" on docker socket
Re-login or run:
```bash
sudo usermod -aG docker ubuntu
newgrp docker
```

### Reclaiming disk space
```bash
docker system prune -a    # removes unused images
```

## 🔒 Security hardening (do these after going live)

1. **Change admin password** (it was shown only once during deploy):
   ```bash
   make mongo-shell
   > db.users.deleteOne({email: "admin@kaamnow.com"})
   > exit
   kubectl -n kaamnow rollout restart deployment/backend
   # On next startup, the seed creates a new admin with the password from the secret
   ```
   To rotate the secret itself, edit `kubectl -n kaamnow edit secret backend-secrets`.

2. **Enable fail2ban** to throttle SSH brute force:
   ```bash
   sudo apt-get install -y fail2ban
   sudo systemctl enable --now fail2ban
   ```

3. **Disable password SSH** (use key-only). Edit `/etc/ssh/sshd_config`:
   ```
   PasswordAuthentication no
   ```
   Then `sudo systemctl restart ssh`.

4. **Auto-renew** Let's Encrypt is built into cert-manager — nothing to do.
